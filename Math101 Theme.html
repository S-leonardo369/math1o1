Introduction to Sets

5 min read · April 20, 2026 · Class 11 · Chapter 1
sets foundations class-11 ncert

A set is simply a well-defined collection of distinct objects. Those objects are called the elements or members of the set. The idea is deceptively simple — but it turns out to be one of the most foundational ideas in all of mathematics.

We write sets using curly braces. For example, the set of the first three natural numbers is written as $A = \{1, 2, 3\}$. We say "1 belongs to A," written $1 \in A$. If an element is not in the set — say, 7 — we write $7 \notin A$.

Tip — Roaster vs. Set-Builder
There are two common ways to describe a set. Roster form lists every element: $\{2, 4, 6, 8\}$. Set-builder form describes the rule: $\{x \mid x \text{ is even}, 1 \le x \le 8\}$. For finite sets, roster is fine; for infinite sets, set-builder is far more practical.

Types of Sets

Not all sets are created equal. Here are the key types you will encounter in Class 11 and beyond.

Empty Set & Singleton

The empty set (or null set) $\emptyset = \{\}$ contains no elements at all. It is unique: there is exactly one empty set. A singleton is a set with exactly one element, like $\{0\}$ or $\{\emptyset\}$.

Watch out — $\emptyset$ vs $\{\emptyset\}$
$\emptyset$ and $\{\emptyset\}$ are not the same! The first has zero elements; the second has one element (that element happens to be the empty set). This trips up a lot of students — always check carefully.

Set Operations

Given two sets $A$ and $B$, we define four fundamental operations. The union $A \cup B$ collects everything in either set; the intersection $A \cap B$ keeps only what they share; the difference $A \setminus B$ removes B's elements from A; and the complement $A'$ takes everything in the universal set that is not in A.

A Worked Example

Let $A = \{1, 2, 3, 4\}$ and $B = \{3, 4, 5, 6\}$. Then:

$$A \cup B = \{1,2,3,4,5,6\}, \qquad A \cap B = \{3, 4\}$$

One very important identity connects these operations. For any sets in a universal set $U$, De Morgan's laws state:

$$(A \cup B)' = A' \cap B', \qquad (A \cap B)' = A' \cup B'$$

These identities appear constantly in probability theory, logic circuits, and database queries — so it's worth getting comfortable with them now.

Cardinality & the Inclusion–Exclusion Principle

The cardinality $|A|$ of a finite set is simply its number of elements. For two overlapping sets, counting the union directly would double-count the intersection. The fix is the Inclusion–Exclusion Principle:

$$|A \cup B| = |A| + |B| - |A \cap B|$$

For three sets it extends to $|A \cup B \cup C| = |A|+|B|+|C|-|A \cap B|-|B \cap C|-|A \cap C|+|A \cap B \cap C|$. This formula is used constantly in combinatorics and probability.
